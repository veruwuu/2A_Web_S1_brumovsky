# Stupid Gacha Ball Game
I think honestly at least I can say that the end product is very creative. I don't know how I came up with this but here we are. 

## Description
Work in an office cubicle for a meager one coin per click, spend it all on gambling (gacha machine), somehow get pictures of dogs from the machine, save the ones you like. It's more fun if you imagine your office cubicle has those dog pictures on the wall now but I don't know how mister Corporateson McBoss will handle it lol.

## Design
I made it just with CSS because I hate new things. The colours are kind of Kirby's and it looks pretty okay. Picked Comic Sans as font because it is kind of a joking project and Comic Sans is great for satire in my professional opinion.
