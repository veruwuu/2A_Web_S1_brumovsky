Kdo byl Charles Babbage

Charles Babbage (1791–1871) byl anglický matematik, filozof a vynálezce. Považován je za „otce počítače“. Jeho návrh analytického stroje je považován za předchůdce dnešních počítačů.

Babbage byl vizionář, který rozpoznal možnost programovatelného výpočtu ještě před vznikem elektřiny.

„Kdyby se moje stroje dokončily, svět by vypadal jinak.“
